## Selected Work · 代表作品

### [ESG RAG Query System](https://github.com/WilliamCHIU-ETH/esg-rag-query-system)　<sub>研究原型</sub>

以台灣企業永續報告建立 RAG 查詢流程，比較三種檢索方法，依 225 筆歷史實驗結果修正設計。

[檢索程式](https://github.com/WilliamCHIU-ETH/esg-rag-query-system/blob/main/src/core/hybrid_retrieval.py) · [研究證據與限制](https://github.com/WilliamCHIU-ETH/esg-rag-query-system/blob/main/docs/public/research-evidence.md)

### [雪隧哨兵](https://github.com/WilliamCHIU-ETH/service-go-live)　<sub>公開案例 · 原始碼私人</sub>

從路況採集、資料新鮮度與 SQLite，到 HTTPS 入口與 CI/CD，整理一個資料服務的架構及交付取捨。

[系統架構](https://github.com/WilliamCHIU-ETH/service-go-live#architecture) · [版本與查驗紀錄](https://github.com/WilliamCHIU-ETH/service-go-live/blob/main/CASE-NOTES.md)

### [航跡工坊](https://github.com/WilliamCHIU-ETH/mapbox-flight-studio)　<sub>影音工具</sub>

用 Remotion 與 Mapbox 製作路線動畫，處理相機高度漂移與渲染缺圖，保留成片、原始碼及量測紀錄。

[觀看成片](https://youtu.be/wgaTxIgL1Jg) · [原始碼](https://github.com/WilliamCHIU-ETH/mapbox-flight-studio/tree/main/projects/ndhu-to-wuling-motorcycle/production) · [驗證紀錄](https://github.com/WilliamCHIU-ETH/mapbox-flight-studio/blob/main/projects/ndhu-to-wuling-motorcycle/verification.md)
